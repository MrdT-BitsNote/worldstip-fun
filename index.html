商圈评级榜

商圈 = 商业核 + 700m 内排他归属的配套密度，单店不构成商圈。评级 = 密度 40% + 丰度 25% + 口碑 25% + 结构 10%；S ≥72 且均分 ≥4.0，A 62–72，B 48–62，C <48。此处只列 S/A 级。

调用示例（curl / Python / jq）与使用说明 
# 全量一次落地（40.1 MB，CDN 自动 gzip / br 压缩）
curl -s https://fun.worldstip.com/data.json -o fun-data.json

# 只要概览：stats 在文件头 4KB 内，Range 取首段即可（省 99.9% 流量）
curl -s -r 0-8191 https://fun.worldstip.com/data.json

# 只要某座城市（Python 标准库，json.load 直接读流）
import json, urllib.request
with urllib.request.urlopen("https://fun.worldstip.com/data.json") as r:
    d = json.load(r)
yy = next(c for c in d["cities"] if c["city"] == "岳阳市")
print(yy["poi_total"], len(yy["food"]), yy["grades"])

# 全国美食榜前 10（评分降序）
curl -s https://fun.worldstip.com/data.json | jq '.food_top[:10]'

# 人类可读全量 Markdown
curl -s https://fun.worldstip.com/data.md -o fun-data.md
  • 两个文件即完整数据集，只读、无鉴权、无速率限制，允许 CDN 长缓存；数据更新时全量刷新。
  • JSON 与 MD 由同一数据层生成，可交叉校验；字段口径见接口文档。
  • 评分/人均为高德快照，采集时间见 data.md 各城市档案头部。
