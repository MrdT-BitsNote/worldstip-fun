API

数据接口文档

两套口径：分片接口按省 / 按城取数，单城约 5–115 KB；全量文件一次拿全部（约 40.1 MB）。所有端点只读、无鉴权、可被 CDN 缓存。服务端（Python / Node / Go）可直接调用；浏览器端跨域需服务端下发 CORS 头，见文末「跨域说明」。

端点总览

端点格式内容体积
/api/index.jsonJSON推荐入口。全国索引：32 省 + 389 城清单、每省数据文件路径与体积、全站统计约 12 KB
/api/provinces/<slug>.jsonJSON省级包：省汇总 + 城市清单（含单城文件路径）+ 本省美食榜 / 商圈榜。slug 为省份拼音，与 moto.worldstip.com 同一套命名（如 hunan）4–51 KB
/api/cities/<adcode>.jsonJSON单城完整档案，与 data.json 的 cities[] 元素逐字段相同（不含任何重算）5–115 KB
/api/food-top.jsonJSON全国美食榜（800 条，已剔除住宿业主导 POI）约 321 KB
/api/districts-top.jsonJSON全国 S/A 商圈榜（703 条，按四维总分降序）约 214 KB
/data.jsonJSON全国全量单文件：meta / stats / provinces（32 省汇总）/ cities（389 城全量明细） / food_top（800）/ districts_top（703）40.1 MB · gzip 约 10.4 MB
/data.mdMarkdown全国全量单文件：目录 + 统计 + 32 省索引 + 389 城档案（每城 13 章）+ 接口与来源附录32.1 MB · gzip 约 10.3 MB

分片接口怎么用

// ① 先取索引（12 KB），拿到省份列表与各自的数据文件路径
const index = await (await fetch('https://fun.worldstip.com/api/index.json')).json();

// ② 按省取：省汇总 + 该省城市清单
const hn = await (await fetch('https://fun.worldstip.com/api/provinces/hunan.json')).json();
// → { province: "湖南省", slug: "hunan", adcode: "43",
//     stats: { cities: 14, poi: 13427, districts: 226, grades: {...} },
//     cities: [ { city: "长沙市", adcode: "430100", poi_total: ..., file: "/api/cities/430100.json" } ],
//     food_top: [...], districts_top: [...] }

// ③ 按城取：单城完整档案（与 data.json 的同名元素完全一致）
const cs = await (await fetch('https://fun.worldstip.com/api/cities/430600.json')).json();

只想看某个城市的美食，取单城包 约 110 KB 即可；旧版必须下 40.1 MB 全量。分片与全量同源同值，可任选其一，也可交叉校验。

调用示例

# 1. 推荐：分片取数。先拿索引（约 12 KB），再按需取省 / 城
curl -s https://fun.worldstip.com/api/index.json | jq '.provinces[] | {province, slug, cities, file}'
curl -s https://fun.worldstip.com/api/provinces/hunan.json | jq '.cities[].city'
curl -s https://fun.worldstip.com/api/cities/430600.json | jq '{city, poi_total, grades}'

# 2. 某城 S 级商圈（只下 110 KB 单城包，不必下 40.1 MB 全量）
curl -s https://fun.worldstip.com/api/cities/430600.json   | jq '.districts[] | select(.grade=="S") | {name, poi, total, center}'

# 3. Python 侧：索引 -> 遍历省份 -> 逐城处理
import json, urllib.request
get = lambda u: json.load(urllib.request.urlopen("https://fun.worldstip.com" + u))
idx = get("/api/index.json")
for p in idx["provinces"]:
    prov = get(p["file"])
    print(prov["province"], len(prov["cities"]), prov["stats"]["poi"])

# 4. 榜单单独取
curl -s https://fun.worldstip.com/api/food-top.json | jq '.[:10]'
curl -s https://fun.worldstip.com/api/districts-top.json | jq '.[:10]'

# 5. 确实需要全量时（约 40.1 MB，CDN 自动 gzip/br）
curl -s https://fun.worldstip.com/data.json -o fun-data.json
curl -s https://fun.worldstip.com/data.md -o fun-data.md   # LLM / skill 直读版

跨域说明（CORS）

浏览器端调用需要服务端配合。本站是纯静态文件，跨域响应头只能由服务器下发，HTML/JS 无法自带。
  • 服务端 / 命令行 / skill / agent：requests、urllib、curl、fetch（Node）不受同源策略约束，现在就能直接用。
  • 网页里的 fetch()：需要服务器在 .json / .md 响应上带 Access-Control-Allow-Origin。本仓库提供三套等价配置，按你的托管方式选一份启用即可： deploy/nginx/fun.worldstip.com.conf（nginx，本站当前使用）、_headers（Cloudflare Pages / Netlify）、.htaccess（Apache）。
  • 不想改服务器：用同源反代（在自己的 Web 服务里转发一次）或把数据落到自己的存储里再造接口。

使用约定

一致性承诺：data.json 与 data.md 由同一数据层（build_api.py）从 data/ 源档案一次生成，同源同值；任一字段都能在 data.md 对应城市档案中找到出处。
  • 无鉴权无限率：静态托管 + CDN 缓存，请合理使用（建议客户端侧缓存 24h）。
  • 评分口径：高德快照评分（0–5），采集时间见各城市 updated 字段；人均单位元。
  • 标记口径：✅ 优质 / ⚠️ 待核 / ❌ 不推荐；派生规则见各城市页说明。
  • 美食榜口径：已剔除名称命中酒店/宾馆/旅馆/民宿/客栈/客舍等关键词、或主类型段为住宿服务的 POI。
  • 变更频率：数据层随采集波次滚动更新，全量文件整体刷新；大版本变更记在方法论页。
  • 许可：数据仅可正当使用，不得整库转售；请保留来源标注（高德/美团/大众点评）。
